项目作品

全栈 + 大模型应用：给工厂做的一体化制造管理平台，还接入了智能经营分析 Agent。

进行中 · 2025.09 至今 · 全栈开发 / 大模型应用

轻量制造管理平台（MES / ERP / WMS）

面向工厂的一体化制造管理平台，覆盖采购、生产、仓储和销售业务，通过事务控制、库存记账与历史快照保障业务一致性， 并接入智能经营分析 Agent，支持销售趋势、客户及商品排行、库存预警和生产缺料的分析与预测。

后端：Java 17 + Spring Boot 3.5 按业务拆模块，Flyway 管理数据库，JPA 负责普通业务、原生 SQL 负责库存与报表；基于 Spring Security 实现认证与 RBAC 授权，Spring Session Redis 管理会话并启用 CSRF 防护。MySQL 是唯一库存来源，靠固定加锁顺序、整单事务、唯一约束与成功记录表保证一致性。
前端：Vue 3 + TypeScript + Element Plus，按权限显示路由、菜单与按钮，工作台用图表，AI 对话用流式返回。
AI：基于 FastAPI 与 LangGraph 构建 Agent，注册 12 个工具，通过 Function Calling 实现受控工具调用；白名单管理有界上下文，MySQL 持久化会话与澄清条件，支持多轮追问、历史恢复及工具逐次鉴权。
